# D-NN-1X-24V120W

低端基本型 BLDC 方波驱动器（NPN 传感器制式，一拖一拓扑）：24V/120W 霍尔无刷电机驱动器的 MM32SPIN030CN 平台实现版，纯开关量控制型，接口兼容德马 EQUBE-P，面向电动辊筒、风机、泵类的 PLC 触点／继电器控制场景。

> 状态：规划中（依据 MM32 平台 PRD V1.0，原理图 BLDC_MM32SPIN V1.0）｜文档更新：2026-10-27

- 产品线：驱动器（D）
- 产品编码：D-NN-1X-24V120W（D=驱动器线，NN=NPN 制式，1X=一拖一拓扑，24V=电压，120W=单板合计额定功率规格码）；型号规则：24V_120W 霍尔无刷电机驱动器-MM32（后续换主控仅改后缀，如 -GD32、-HPM）
- 适用客户：辊筒厂、输送设备厂（直销）
- 关键规格：DC 24V 单电源（TVS SMBJ26A 防护）；额定母线电流约 5A；PWM 频率 16–20kHz；主控 MM32SPIN030CN（QFN28，集成 PN 栅极驱动器与 5V LDO）；功率级高侧 AP40P04Q ×3 + 低侧 SP40N05GNU ×3（栅阻 22Ω）；母线低边 20mΩ 采样电阻 + 片内运放；辅助电源 24V→47Ω 限流→78M05→+5V

### 对外接口总览

| 端子 | 型号 | 引脚定义 |
| --- | --- | --- |
| CN1 电源输入 | WJ2EDGRC-5.08-02P-14-00A（2P 5.08mm） | 1=24V−(GND)，2=24V+ |
| CN2 电机+霍尔 | HC-5557-4.2-2x4AW（2×4P 4.2mm） | 1=U，2=HW_IN，3=V，4=HV_IN，5=W，6=HU_IN，7=+5V，8=GND |
| U1 控制信号 | S6B-PH-K-S(LF)(SN)（6P 2.0mm PH） | 1=COM_P24，2=FAULT_OUT，3=REV，4=RUNA，5=RUNB，6=COM_N24 |
| TP1–TP4 | 测试点 | TP1=运放偏置，TP3=SWDIO，TP4=SWCLK（调试／烧录） |

### 控制通道（光耦隔离，现场侧 24V，低有效，不共地）

RUN A / RUN B —— 调速与启停：

| RUN B | RUN A | 状态 |
| --- | --- | --- |
| OFF | OFF | 停止（封波滑行） |
| ON | OFF | 100% 速度运行 |
| ON | ON | 75% 速度运行 |
| OFF | ON | 50% 速度运行 |

REVERSE —— 反转输入：启动时采样 REVERSE 电平决定转向；运行中 REVERSE 跳变 → 停机后按新方向重新启动（禁止带电换向）。

FAULT_OUT —— 故障输出（S8050 集电极开漏，24V 域）：正常＝断开，任一故障（E1–E6）＝导通；同时板载 LED 快闪故障码。

接线公共端：COM_P24 / COM_N24（现场侧 24V 正／负，与板内控制地光耦隔离，不共地）。

### 板载 5 位拨码（SW1，ADC 分压采样，非对外端子）

| 拨码位 | 名称 | 功能 |
| --- | --- | --- |
| 1/2 | 加减速档 1/2 | 4 档加减速时间：0.1s / 0.3s / 0.5s / 1.0s |
| 3 | 默认方向 | 停机时初始转向；REVERSE 有效时取反 |
| 4/5 | 速度档 1/2 | 4 档速度预设（对 RUN A/B 三档比例的独立修正） |

拨码 ADC 档位电平（5V 基准，每组两位 10k/20k 二进制加权）：

| 组合 | 全开 | 仅 20k 位闭合 | 仅 10k 位闭合 | 全闭合 |
| --- | --- | --- | --- | --- |
| 电压 | 5.00V | 3.33V | 2.50V | 2.00V |
| 判决阈值 | 4.17V | 2.92–4.17V | 2.25–2.92V | <2.25V |

### 接线步骤

1. CN1 接 24V 电源（1=24V−/GND，2=24V+，注意极性）。
2. CN2 接电机三相 + 霍尔（U/V/W 对应 1/3/5，霍尔 HU/HV/HW 对应 6/4/2，7=+5V，8=GND）。
3. U1 接 PLC 开关量信号：1=COM_P24、6=COM_N24 为现场侧 24V 公共端，与板内控制地隔离不共地；2=FAULT_OUT、3=REV、4=RUNA、5=RUNB 对应接入。
4. 板载拨码 SW1 选加减速档、默认方向、速度档（非对外端子）。
5. 运行验证：RUN B 置 ON → 100% 速度运行；LED 常亮为正常；故障时看 LED 快闪次数对故障码表。

### 指示与保护

单灯多状态：待机慢闪 1Hz / 运行常亮 / 故障快闪 N 次循环。

故障码一览：

| 故障码 | 保护项 | 阈值 | 动作 |
| --- | --- | --- | --- |
| E1 | 瞬时过流 | 15A | 立即封波，锁定，断电清除 |
| E2 | 过载（I²t） | 9A 持续 500ms | 封波停机，自动恢复重试 |
| E3 | 堵转 | 霍尔 300ms 无跳变且电流>5A | 封波停机，锁定 |
| E4 | 启动失败 | 1s 内无霍尔脉冲 | 停机，重试 2 次后锁定 |
| E5 | 过压 | 29V | 封波停机，回滞恢复 |
| E6 | 欠压 | <18V | 封波停机，回滞恢复 |

锁定型（E1/E3/E4）需断电清除；E2/E5/E6 自动恢复（连续 3 次转锁定）。

## 快速上手

1. 接线：CN1 接 24V 电源（注意极性），CN2 接电机三相 + 霍尔，U1 接 PLC 开关量信号（COM_P24/COM_N24 为现场侧公共端，与板内控制地不共地）。
2. 设置：板载拨码选加减速档、默认方向、速度档。
3. 运行：RUN A/B 编码调速；REVERSE 控制转向。
4. 故障排查：看 LED 快闪故障码（E1–E6），锁定型故障（E1/E3/E4）断电清除。
